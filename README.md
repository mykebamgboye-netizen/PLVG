# PluggedIn Starter (Preview)

This is a minimal starter scaffold generated by ChatGPT for the PluggedIn social marketplace concept.
It contains a Next.js App Router structure with TypeScript and Tailwind placeholders, server wrappers for Genkit,
a NextAuth/Prisma schema, and Supabase helpers.

## Quick start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Create .env.local with at least:
   ```
   DATABASE_URL="file:./dev.db"
   NEXTAUTH_SECRET="change-me"
   GENKIT_API_KEY="sk-..."
   GENKIT_BASE_URL="https://api.genkit.example"
   SUPABASE_URL="https://your.supabase.co"
   SUPABASE_ANON_KEY="anon-..."
   ```

3. Run Prisma migrate:
   ```bash
   npx prisma migrate dev --name init
   ```

4. Run dev server:
   ```bash
   npm run dev
   ```

This starter is for prototyping and contains mock UI and placeholders. Replace Genkit wrapper calls,
wire NextAuth providers, and implement your production backend as needed.

## Deployment Guide

### Vercel
1. Push repo to GitHub.
2. Import project to Vercel and set environment variables (DATABASE_URL, NEXTAUTH_SECRET, GENKIT_API_KEY, GENKIT_BASE_URL, SUPABASE_URL, SUPABASE_ANON_KEY).
3. Set Node version to >=18.

### Supabase
- Create a Supabase project and run the SQL to create `messages` table.
- Add service role key to environment if you plan to run server-side operations.

### Genkit
- Provide your Genkit API credentials and ensure `GENKIT_BASE_URL` points to the correct endpoint. Use server-side calls only.

### Notes
- Replace demo Credentials provider with production OAuth providers for NextAuth.
- Do not commit secrets; use project settings on Vercel or other host.


## Push Notifications (Web)

1. Generate VAPID keys (locally or via a tool):

```bash
npx web-push generate-vapid-keys --json > vapid.json
```

2. Add `VAPID_PUBLIC_KEY` and `VAPID_PRIVATE_KEY` to your environment in Vercel or `.env.local`.
3. Ensure `public/sw.js` is present (it is included in this project) and that `usePushNotifications` is called client-side to subscribe users.

Server-side, implement `lib/webpush.server.ts` using the `web-push` library to send notifications to saved subscriptions.

## Supabase Storage

- Use the `UploadImage` helper to store avatars, product images, and AI-generated images in Supabase Storage. Make sure `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` are set.
